<h2><a href="https://www.geeksforgeeks.org/problems/heapify-the-vector--102013/1">Building Heap from Array</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given an integer array <strong>arr[]</strong>, build a Max Heap from the given array.</span></p>
<p><span style="font-size: 18px;">A Max Heap is a complete binary tree where each parent node is greater than or equal to its children, ensuring the largest element is at the root.</span></p>
<p><strong><span style="font-size: 18px;">Note: </span></strong><span style="font-size: 18px;">The driver code prints true if the resulting array represents a valid Max Heap; otherwise, it prints false. Multiple valid Max Heap arrangements are possible.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input:&nbsp;</strong>arr[] = [4, 10, 3, 5, 1]<br></span><span style="font-size: 18px;"><strong>Output:</strong> true<br><strong>Explanation:</strong> The resulting array represents a valid Max Heap, with 10 as the root and every parent greater than or equal to its children.<br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/933461/Web/Other/blobid0_1788586861.webp" width="228" height="195"></span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [1, 3, 5, 4, 6, 13, 10, 9, 8, 15, 17]<br><strong>Output: </strong>true<br><strong>Explanation:</strong> The resulting array forms a valid Max Heap, where 17 is the largest element at the root and each parent is greater than or equal to its children.<br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/933461/Web/Other/blobid2_1788587080.webp" width="349" height="193"><br></span></pre>
